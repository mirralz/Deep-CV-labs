# Object Detection with Faster R-CNN

## Цель

Реализация модели обнаружения объектов на основе Faster R-CNN для локализации мячей на изображениях.

## Суть

- Использован предобученный Faster R-CNN (`torchvision.models.detection`)
- Датасет кастомный, аннотированный вручную (формат: изображения + bounding boxes)
- Модель дообучена и адаптирована под один класс: "ball"
- Реализован inference на новых изображениях
- Порог уверенности детекции настроен для стабильного вывода

## Результат

Модель уверенно находит мячи при различных условиях освещения и фона.  
Код готов к дообучению под другие классы или расширение датасета.
