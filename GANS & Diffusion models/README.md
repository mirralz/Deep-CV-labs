# Class-Conditional Image Generation with Diffusion Models (DDPM)

## Цель

Реализовать генерацию изображений по заданной категории с помощью диффузионной модели.  
Применить метод Classifier-Free Guidance для управления содержимым генерации, альтернативно GAN-подходам.

## Этапы

- Построена DDPM-модель с поддержкой условной генерации
- Внедрён Classifier-Free Guidance:
  - часть данных обучалась без метки
  - на inference подаётся метка для генерации изображения нужной категории
- Обучение проведено на датасете с категориями одежды/обуви
- Реализована визуализация результатов по меткам

## Результат

Модель различает классы и генерирует изображения, соответствующие заданной категории.  
Структура объектов сохраняется, несмотря на шум и отсутствие дискриминатора.
