# Image Classification with EfficientNet-B0 (Kaggle Challenge)

## Цель

Построить модель для классификации изображений одежды и аксессуаров из 20 классов в рамках соревнования на Kaggle. Добиться точности выше 0.5.

## Подход

- Использована EfficientNet-B0 с предобученными весами
- Базовая часть заморожена, финальный слой модели заменён на полносвязную сеть, адаптированную под 20 классов
- Обучение проводилось с использованием:
  - Аугментаций (RandomResizedCrop, HorizontalFlip, ColorJitter)
  - Оптимизатора AdamW + OneCycleLR
  - CrossEntropyLoss
  - Инференс и форматирование submission-файла в соответствии с Kaggle

## Результат

- Accuracy на обучающей выборке: 81.9%
- Score на Kaggle: **0.87507**
- Модель стабильно предсказывает классы даже на сложных образцах
