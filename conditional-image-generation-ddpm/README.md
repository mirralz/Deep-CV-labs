# Class-Conditional Image Generation with Diffusion Models

## Цель

Обучить диффузионную модель (DDPM) генерации изображений на основе заданной категории (одежда, обувь и т.д.), используя метод Classifier-Free Guidance.

## Метод

- Используется DDPM-архитектура с модификацией под условную генерацию
- В качестве условия — классовая метка (label)
- Внедрён подход Classifier-Free Guidance: во время обучения часть примеров подаётся без меток, чтобы повысить устойчивость модели
- Реализована генерация изображений по конкретным меткам

## Результаты

Модель способна генерировать изображения, соответствующие заданным категориям.  
На визуализациях различие между классами сохраняется, структура объектов передаётся корректно, несмотря на низкое разрешение.
